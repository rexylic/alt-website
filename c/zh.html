New Pinyin

This is a transcription system for Mandarin Chinese, designed to replace Pinyin.

What's wrong with Pinyin

Not necessarily anything. It has served its purpose dutifully, so it's more that I don't agree with some of its design choices.

For example, I don't like how "bian" doesn't actually have the same "a" sound as in "xia". I also don't like how "j", "q", "x" are always followed by "i", feels redundant.

If a character sound starts with a vowel and does not follow a space, prepend an apostrophe, like so: si'an.

The only non-ASCII symbol used is ı, which usage (I think) is perfectly justified. It's a wonderful letter. Optionally, you may substitute letter runs with the following:

ŋ for ng č for ch š for sh ž for zh
y for iu é for ei ó for ou

Sample

Here's a sample passage with Pinyin, the same passage written in my system, and the same passage with all substitutions.

renren sheng'erziyou, zai zunyan he quanli shang yilü pingdeng. tamen fuyou lixing he liangxin, bing ying yi xiongdi guanxi de jingshen xiang duidai.

renren sheng'erzı'iou, zai zuen'ien he ciuenli shang iliu pingdeng. tamen fuyou lising he liangsin, bing ing i siongdi guansi de zingshen siang dueidai.
